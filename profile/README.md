# OSCEIA Tech

Somos a área de tecnologia da **OSCEIA**. Construímos soluções digitais que apoiam programas sociais e educacionais, como Jovem Aprendiz e Estágio, com foco em simplicidade, segurança e impacto real para as pessoas atendidas.

## 🚀 O que temos feito

- **Plataformas web e aplicativos** para cadastro, acompanhamento de inscrições, vagas e formulários.
- **Sistemas internos de gestão**: contratos, faturamento, projetos, prestação de contas e acompanhamento pedagógico.
- **Integrações e automações** entre sistemas, para reduzir trabalho manual e manter os dados conectados.
- **CRM e gestão de relacionamento** com candidatos, parceiros e empresas.
- **Presença institucional e comunicação digital**, com sites e materiais de divulgação.
- **Documentação e arquitetura**: análise de sistemas legados, decisões técnicas e especificação de módulos.
- **IA aplicada**: automações e habilidades inteligentes que apoiam as rotinas do ecossistema OSCEIA.

> Nossos projetos são, em sua maioria, privados. Aqui compartilhamos apenas uma visão geral do nosso trabalho.

## 🛠️ Tecnologias

| Área | Tecnologias |
| --- | --- |
| Front-end | TypeScript, React, HTML, CSS |

| Dados | PostgreSQL |
| Automação e integrações | n8n, webhooks, APIs REST |
