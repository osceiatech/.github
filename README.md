# OSCEIA Tech 💙

Espaço de tecnologia da **Obras Sociais do Centro Espírita Irmão Áureo (OSCEIA)**.

Desenvolvemos ferramentas digitais para facilitar o trabalho das equipes e ampliar o alcance dos nossos programas sociais: desde a captação de inscrições até o acompanhamento dos atendidos.

## 📂 Projetos

### [portal-jovem-aprendiz](https://github.com/osceiatech/portal-jovem-aprendiz)
Portal de cadastro para o programa **Jovem Aprendiz**.
- Landing page com **formulário multi-etapa**, pensado para ser simples de preencher pelo celular.
- Os dados são enviados por uma automação no **N8N** e registrados no **Twenty CRM**, para que a equipe acompanhe cada inscrição.
- Stack: TypeScript.
